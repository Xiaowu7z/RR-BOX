# 微信、抖音与 TikTok 分流验收

这一轮优先保证微信和国内抖音使用本地解析与直连，国际 TikTok（包括改包名的第三方客户端）使用代理解析与代理出口。微信内置浏览器、小程序的外部网站按目标地址独立分流，不把整个微信进程排除出 VPN。共享云服务域名不整体加入离线白名单。

## 三种验证结论必须区分

| 验证 | 能证明 | 不能证明 |
|---|---|---|
| JVM 单元测试 | 生产配置生成、规则优先级、DNS 与路由条件一致、模式切换 | sing-box 实际解析与匹配结果 |
| `verify-routing.py` 原生内核验收 | 固定版本 core 对生产规则的真实 TCP/UDP/DNS 匹配、海外优先、域名边界、原始配置可加载、完整 SRS 解码 | 安卓 UID、真实 TUN/HEV 转发、网络切换、手机耗电、应用账号操作 |
| 安卓实机验收 | 下表中的实际业务可用性、切网和恢复体验 | 所有地区、运营商、应用版本永久适配 |

`--self-test` 只校验测试工具自己的 SOCKS/DNS 编解码，不能作为原生内核或实机验收通过的证据。实际执行结果查看本次构建的 `build-reports/ROUTING-CORE-REPORT.json`；没有通过报告时，不标记原生验收完成。

## 原生内核验收方法

`RoutingFixtureExportTest` 调用生产 `ConfigBuilder` 与 `HevConfigAdapter`，导出 System/HEV 各三份配置：智能分流＋离线补充、智能分流＋APK 内置 SRS、关闭智能分流。工具先对未修改的每份配置运行 `sing-box check`，再保留生产路由和 DNS 规则原文执行本机探测。

为了不需要 root/TUN、真实节点或应用账号，测试仅替换以下环境部分：

- TUN 入口替换为保留原入口 tag 的本机 SOCKS 入口；HEV 的原生 C 转发器不参与此测试。
- `direct` 和 `proxy` 出口替换为两个不同的本机 SOCKS 观测端，分别返回出口名称。观测端不会访问请求的真实域名或 IP。因而公网/国内/局域网 IP 都可以作为真实匹配输入，而不会产生外网流量。
- 两个上游 DNS 的传输替换为两个本机 UDP DNS，应答分别为 `223.5.5.5` 和 `1.1.1.1`。`dns.rules`、`dns.final` 和缓存策略保持生产配置。本测试验证解析服务选择，不验证生产 DoT 的 TLS 握手、DNS 上游可达性或 direct 出口的真实拨号解析。
- 日志提高到 debug；关闭测试环境不需要的默认接口自动检测。

工具不使用自行实现的路由匹配器。TCP 域名请求、UDP 域名请求、IP 请求、HTTP Host 与真实 TLS ClientHello 都进入 sing-box 的实际规则引擎；DNS 请求通过同一入口进入生产 `hijack-dns` 规则。

覆盖内容：

- 微信登录/消息、图片文件、视频号/直播、小程序网关与支付域名。
- 抖音信息流、评论私信入口、图片视频、直播上传、商城支付域名。
- TikTok API、图片视频、国际对象存储、直播、US/EU 域名及限定的 CDN 别名。
- TikTok 域名配合国内目标 IP，验证海外规则优先于国内 IP 规则；不依赖官方包名。
- `douyin.com.evil.invalid` 等相似域名不能命中国内后缀；普通 Akamai/公共 CDN 域名不能因为 TikTok 的限定别名被全域扩展。
- TCP/UDP 形式的国内外 IPv4/IPv6 和局域网地址；UDP/443 与 STUN 端口可传输，不代表真实 QUIC 或音视频会话已通过。
- UDP/TCP DNS、节点域名启动解析、关闭智能分流后的代理默认策略。
- 未命中国内域名集、但模拟 DNS 返回国内 IP 的对照：域名形式继续代理，真实 IP 形式在完整国内 IP 集下直连，记录 HEV 当前不自动解析的边界。
- 合法内置 SRS 可被 core 加载；合法 `SRS` 文件头和 zlib 数据、但错误规则内容，必须被完整解析拒绝。

域名用例在 `scripts/verify-routing-cases.json`，并记录维护规则源的 URL 和 Git blob SHA。部分子域名是覆盖后缀匹配的代表性/合成探针，不冒充抓包所得的完整端点清单。`shared-cdn-maintained-srs` 样例依赖完整国内 SRS；当 SRS 不可用时，这些共享服务遵循默认代理，不为扩大离线覆盖而把整个云平台加入直连。

在构建出固定版本 libbox，并完成 Release JVM 测试后运行：

```bash
test "$(git -C sing-box-src rev-parse HEAD)" = 0b8995879f29a9b98ee027bc17b75e101445b238
mkdir -p build-reports
cd sing-box-src
go build -ldflags '-X github.com/sagernet/sing-box/constant.Version=1.14.0' -o ../build-reports/sing-box-host ./cmd/sing-box
cd ..
python3 scripts/verify-routing.py --sing-box build-reports/sing-box-host --fixtures app/build/routing-fixtures --report build-reports/ROUTING-CORE-REPORT.json
```

工具还校验二进制 `version` 输出中的版本与 VCS Revision，并记录二进制、域名用例与实际 SRS 的 SHA-256。失败返回非零退出码。所有被测配置和 native debug 日志放在报告旁的 `routing-core-details/`。

## 当前有意保留的边界

固定的 sing-box 1.14.0 不会在遇到 IP 规则时自动解析一个 SOCKS 域名。HEV 原生映射后交给 core 的未知域名，如果未命中国内域名集，将走默认代理；System 若拿到真实国内 IP，可命中国内 IP 直连。新增全局 `resolve` 会增加首次连接的串行 DNS 等待，且解析失败会中断本可交由代理服务器解析的连接，因此本轮不增加这项行为。

System 的 DNS 反向映射是尽力恢复域名，不保证能识别应用自带 DoH、HTTPDNS、裸 IP、共享 IP 的所有用途。原生测试替换了 TUN 入口，所以不能用两个入口 tag 的结果一致声称整个 System/HEV 数据链路已经等价。

TikTok 的精确包名代理保护位于域名规则前，使用“包名匹配且目标未命中私网”的条件；域名尚未解析时也可能满足后一个条件。它不改变既有私网规则顺序。System 的 Android 10+ 身份查询成功时可补强共享 CDN/IP 场景，HEV 或身份未知时该条件不命中。主机配置检查能验证此规则格式，不能证明 Android UID 归属已经实机验证；DNS 不复制这条包名条件。

微信小程序可接入开发者自己的服务器，第三方 TikTok 插件也可能访问插件作者的更新或登录服务。未知第三方域名按通用规则处理；应根据实测连接补规则，不对未知服务按名称猜测直连。

## 安卓实机验收表（逐项记录，初始为待测）

每项先记录手机/系统、APP 版本、RRBOX 构建 SHA、SRS SHA、节点、运营商，再分别用 System/HEV、Wi-Fi/移动网络执行。两次测试使用同一节点、同一内容和相近时间，避免把线路变化当成客户端收益。

| 应用/场景 | 操作 | 验收观察 |
|---|---|---|
| 微信消息/通知 | 单聊、群聊、图片、文件；后台锁屏后接收 | 消息及时，无异常反复连接；打开原图/文件正常 |
| 微信语音/视频 | 语音消息收发、实时语音、视频通话 | 双向可用，无单通；持续通话与切网分别记录 |
| 微信视频号/直播 | 连续刷视频、拖动、横竖屏、进入直播 | 首帧、停顿次数、直播恢复时间 |
| 微信小程序/支付 | 常用小程序、扫码、支付页面、微信内国内外网页 | 页面与跳转正常；境外页面保留代理，支付用用户日常操作确认 |
| 国内抖音 | 连续视频、搜索、评论、私信、图片 | 国内业务命中直连；首帧与卡顿记录 |
| 抖音直播/上传 | 进入直播、评论、私信；有意发布时再上传 | 播放和上行都正常；不为测试擅自发布内容 |
| 国际 TikTok 第三方版 | 登录状态、信息流、搜索、评论、私信、直播 | 国际 API/CDN 始终代理；不因包名变化走直连 |
| 日常国内 APP | 支付宝、淘宝、京东、美团、地图、B站、小红书等 | 登录、图片、视频、定位相关页面无异常；不代用户下单 |
| 网络切换 | Wi-Fi→移动→Wi-Fi，锁屏、后台恢复 | 记录中断与恢复时间；已有失败连接可重建 |
| 主动断开 | 手动断开 VPN 后切网/锁屏/恢复 | 保留主动断开状态，不自行连接 |
| IPv6/UDP | 双栈网络、IPv4 网络，直播与通话 | 无异常等待；区分节点 UDP 能力与客户端分流 |

需要记录“通过 / 失败 / 未测试”，失败时记录实际目标域名或 IP、命中出口和可复现步骤。不得把核心域名规则覆盖率写成微信、抖音或 TikTok 全功能已实测通过。
