# 1.0.0 源码检查与修复记录

## 范围与方法

基线为 `be1ac6e83fc1d729535621459850d61098d2ffe4`。检查对象覆盖本仓库 Kotlin 生产代码与测试、Android Manifest / XML 资源、Gradle 依赖声明、脚本、文档和正式发布链；重点人工审查导入、节点持久化、VPN 生命周期、Quick Settings、物理网络回调、分流、诊断、PIN 与更新入口。

全仓文件清单、哈希及结构检查由 `scripts/source_audit.py` 输出；源码断言由 `scripts/source-regressions.sh` 输出；Gradle 对所有生产源码编译、运行全部 Release 单元测试及 Android Lint。源码 grep 不是运行测试，JUnit 不是实机测试。测试数量 / Lint 结果以本次成功 CI 的 `TEST-REPORT.json` 为准，不在文档中预先写“全部通过”。

## 已针对性修复

| 位置 | 风险 / 缺陷 | 修复 |
|---|---|---|
| URL 与导入 | 入口分类不一致、非法地址误判、超大 / 特殊 YAML 输入 | 统一分类、歧义询问、URI 校验、字节 / 数量限制、安全构造器 |
| 订阅名称覆盖 | 单纯改名保存全配置，后续订阅新密码被旧值盖住 | 名称覆盖只作用于新 base 的 tag，兼容迁移旧的纯改名记录 |
| 节点身份 | 订阅数组下标变化时旧覆盖可能错配 | 全批次优先保留唯一内容匹配，再唯一端点匹配，歧义分配新 ID |
| 本地存储 | 并发导入 / 修改基于旧列表覆盖新数据 | Room 事务读取最新数据再修改，UI 观察已提交数据 |
| 节点编辑 | Raw 中密码 / SS method 修改未写回，或保存不可用配置 | 精确补丁写回，保留未知字段，保存前 libbox 校验 |
| Quick Settings | 缓存忽略当前节点内容，使用已删除 / 编辑前的配置 | 当前配置逐项比较；旧缓存无完整状态不复用；省去应用枚举 |
| Android 14+ | 授权跳转使用过期的 Intent 重载 | PendingIntent 重载与旧系统分支 |
| VPN 停启 / 恢复 | 旧停止任务影响新连接，已排队恢复可能违背断开意图 | 请求代次检查、恢复意图复核、缺失配置时完成前台服务清理 |
| 运行缓存 | 文件替换可能暴露半写内容或混入变化后的节点标签 | AtomicFile 与跨实例锁，保存请求快照 |
| 物理网络 | libbox 只收到启动快照；同接口新 Network / 离线被遗漏 | 持续监听，签名包含 Network / DNS / 健康状态，关闭时注销 |
| TLS | HY2 / TUIC 无条件 insecure=true | 默认校验证书；导入与 UI 明确保留用户不安全选项 |
| 日志 / 更新 | 引号包裹 JSON、URL 路径 token 未脱敏，更新资产 URL 未限制 | 集中脱敏，更新响应限流量 / 超时、稳定版与本仓库资产校验 |
| 发布链 | 更新 Release target 并不自动同步已有 Git tag | 发布前快进 tag、发布后校验 asset digest、源码 / 二进制可追溯 |

## 保持不变

版本 1.0.0 / 100、包名、正式签名密钥、System 默认、HEV 固定核心、MTU / 分流基础拓扑、已验收图标和状态栏资源。没有增加自动选节点或隐式切换业务线路。

## 验证边界 / 待实机验收

本轮是源代码层面的完整构建与检查，不是所有 Android 设备的端到端验证。未在实体手机执行覆盖安装、连续息屏、ROM 后台限制、多运营商切网、所有协议的真实服务端握手、长时间压测或新版性能 A/B。运行中的 native 资源销毁、网络回调时序和系统后台策略仍需设备验收；自动化通过不能证明不存在其他 bug。

存量自签 HY2 / TUIC 可能需要显式启用不安全证书选项。Raw 导入不等于完整 sing-box 客户端配置兼容。极端并发跨屏操作、整机断电与文件系统错误不能仅由普通 JVM 单测覆盖。

仓库 About 元数据需要独立的 GitHub 管理授权；README / 发布说明更新不代表 About 字段已成功变更。本项目没有新增项目级许可证，本次只是补全第三方来源说明与已授权的许可证文本。
