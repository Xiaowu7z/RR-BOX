# RRBOX 使用说明

## 从订阅开始

进入“订阅 → 添加订阅”，填入 HTTP/HTTPS 地址和可选名称，点击“添加并同步”。也可在“节点 → ＋”从剪贴板、相机、图片或文本导入。带认证的根 HTTP 地址通常按代理节点处理；根订阅或带认证的资源地址有歧义时请选择“作为订阅”。失败不会创建空订阅组，输入框使用后自动清空。

主导入上限为 8 MiB、2048 个节点，Network Lab Raw 上限 256 个。订阅返回普通网页、无效格式或超限内容不会作为成功订阅保存。

## 选择、命名和编辑

展开节点组，点选节点，再到仪表盘连接。仅选择节点不会自动重启当前 VPN；当前运行中的本地节点受到删除保护。

右侧菜单“重命名”改变显示名字；“编辑节点”改变实际连接配置。“恢复订阅值”清除该订阅节点全部本地覆盖，包括自定义名称。刷新时只在能唯一匹配身份的情况下继承名称；若服务器、名称和认证同时变更或出现重复项，可能视为新节点，避免覆盖误配。

保存前检查配置；编辑正在使用的节点不会擅自打断当前连接。断开重连或下次使用快捷开关时采用最新参数。

Ping 是服务器 ICMP 延迟，不是完整代理协议测速。部分服务器禁用 ICMP，显示超时不必然说明代理节点不可用。测速时先断开 VPN，避免当前代理路径影响结果。

## 引擎和分流

默认 System；HEV 是可选 native 路径，不保证对每条线路更快。出现兼容问题先回到 System。Network Lab 的 A/B 和恢复演练会重建或暂时停止数据面，测试期间已有连接可能中断，不应在重要通话 / 下载时运行。

“全部代理”“仅选中应用代理”“选中应用绕过”互斥。仅选中应用模式至少选择一项；大陆分流另行决定捕获流量中的国内域名 / IP 直连，依赖已加载规则。

## 证书错误

新版默认校验 HY2 / TUIC 的服务器证书。先核对服务器时间、域名、SNI 与证书信任链。确实使用自签证书且已确认服务器身份时，可在编辑页显式开启“跳过 TLS 证书校验（不安全）”；这会降低身份验证保护。Raw 模式以 JSON 字段为准，切勿为普通网络故障盲目关闭验证。

## 更新同版本修复包

本轮保持 `1.0.0 / 100`。请从正式 Release 重新下载安装，覆盖原安装而不是卸载。App 内检查更新使用版本号；同版本替换可能不会提示，Obtainium 也可能需要主动重新安装。核对构建报告的 source commit 与 APK SHA-256。

## 反馈问题

提供 Android 版本、机型、引擎、Wi-Fi / 蜂窝环境、协议类型、重现步骤和构建哈希；不要公开订阅链接、密码、UUID 或私钥。Network Lab 日志自动脱敏并不覆盖所有自定义字段，发送前请自己检查。涉及真实凭据先撤销 / 轮换，再提交不含敏感值的复现。
